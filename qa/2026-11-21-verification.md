# TicketGuard AI 모델 추출과 TXT 저장 검증

## 실행 조건

2026년 11월 21일에 사전에 정답을 고정한 한국어 합성 판매글 10건을 기존 프롬프트로 한 번, 출력 형식과 금액 근거 검사를 수정한 뒤 같은 문장으로 한 번 실행했다. 두 실행 모두 실제 모델 응답을 10건씩 받았다. 정답은 모델 요청에 포함하지 않았다. 두 번째 실행은 수정에 사용한 사례를 다시 검사한 결과이므로 독립 평가셋 성능과 구분한다. [평가 문장과 정답](../audience/evaluation/novel_posts.json)

모델은 Qwen2.5-1.5B-Instruct Q4_K_M, 서버는 llama.cpp b12606이었다. GGUF SHA-256은 `6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e`이다. 루프백 HTTP에서 OpenAI Python SDK와 관객 앱의 공통 추출 요청 함수를 사용했다. OpenAI가 운영하는 gpt-4o-mini API는 이 실측에서 호출하지 않았다. ## 모델 실측 결과

첫 실행에서는 10건 모두 행사 분류에 허용되지 않는 문자열 `PERFORMANCE/SPORTS`를 반환해 검사를 통과하지 못했다. 이후 JSON 스키마에 허용값을 지정하고, 묶음 판매에서 장당 표현이 가리키는 금액을 확인하도록 변경했다.

| 보완 후 지표 | 결과 |
| --- | ---: |
| 실제 모델 응답 | 10/10 |
| 앱의 응답 검사 통과 | 8/10 |
| 행사명 일치 | 6/10 |
| 행사 일자 일치 | 8/10 |
| 좌석 등급 일치 | 8/10 |
| 장당 가격 일치 | 6/10 |
| 네 항목을 모두 정확히 추출 | 4/10 |

검사에서 거절된 응답은 네 항목 모두 실패로 집계했다. 정답이 미기재인 필드에는 모델 결과도 null이어야 일치로 인정했다.

| 사례 | 결과 | 관찰 내역 |
| --- | --- | --- |
| N01–N04 | 네 항목 모두 일치 | 만원·천원, 두 좌석의 장당 가격, 총액만 있는 글의 가격 미확인을 포함한다. |
| N05·N06 | 각 3/4 일치 | 행사명 끝의 ‘콘서트’를 누락했다. |
| N07 | 3/4 일치 | 무료 나눔의 정답은 0원이고, 반환한 구입 제시액은 확인 불가였다. |
| N08 | 응답 검사에서 거절 | 원문에 없는 근거 구절을 인용했다. |
| N09 | 3/4 일치 | 두 장 합계 20만 원과 장당 10만 원이 같이 적힌 글에서 장당 가격을 확정하지 못했다. |
| N10 | 응답 검사에서 거절 | 일자에 JSON null 대신 문자열을 넣었다. |

## TXT 검증

휴대폰용 확인 화면에서 사례를 선택하고 TXT를 내려받은 뒤, 기기 파일 선택창으로 같은 파일을 다시 연다. 선택 파일 내용은 기기에서만 처리한다. 원본과 저장본의 SHA-256, 한국어 네 구획, 사례의 장당 금액을 대조한다. 단순히 다운로드 이벤트가 발생한 것과 구분한다. [휴대폰 확인 화면](https://ticketguard-ai-demo.tart-hippo-0446.chatgpt.site/mobile-check)

2026년 11월 22일 Android 13 에뮬레이터(`sdk_gphone64_x86_64`, Chrome `109.0.5414.123`)에서 공개 사이트의 세 사례를 각각 내려받고 Android 파일 선택창으로 다시 열었다. 세 사례 모두 한글 네 구획과 장당 금액이 일치했다. 저장본, 공개 사이트의 HTTPS 응답, 같은 소스에서 빌드한 TXT의 바이트 수와 SHA-256도 각각 일치했다. [Android 실행 로그](https://github.com/BAYERNA/TrueTicket/actions/runs/44966129498/job/137035449528)

실물 스마트폰에서 저장 후 재열기를 확인한 기록은 아직 없다. 실기기에서 확인하면 공개 확인 화면의 ‘확인 결과 복사’에 사례, 크기, 금액, 해시, 브라우저 정보와 시각이 표시된다. [기준값 산출 코드](report_bytes.mjs) · [Android 기기 점검 코드](android_txt.py)

## 후속 자동 검사

관객 앱 테스트 24개와 통합 웹 테스트 6개가 통과했다. 관객 앱 검사에는 두 장 합계 20만 원과 장당 10만 원이 한 문장에 있을 때 장당 10만 원만 인정하는 사례가 포함된다. 저장소 검증 환경에 OpenAI API 키가 설정되지 않아 이번 실행의 OpenAI 운영 API 호출은 0건이다. 위의 로컬 Qwen 실측은 같은 10문장을 두 번 평가한 총 20회 응답이다.
