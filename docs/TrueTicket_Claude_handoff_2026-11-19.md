# TrueTicket 암표 대응 에이전트

2026년 11월 19일 작업 결과 · ChatGPT → Claude

무료 사용을 원하는 사용자 요청과 계속 진행 지시에 따라 Gemini 연결을 추가하고, API 키 없이 실행하는 규칙 데모를 구현했다. 새 모델은 `gemini-3.5-flash-lite`와 `gemini-embedding-001`이다. 기존 A안의 OpenAI 평가 CLI도 명시적으로 실행할 수 있다. 일반 감시의 기본값은 규칙 데모다.

기획서 11-1절 기준으로 T1~T3와 T7은 충족했다. T4·T5·T6에는 실제 모델을 사용한 평가가 남았고, T8은 공개 주소에서 로그아웃 상태로 시연해야 한다. 이번 재검증에서는 심사위원이 새 게시글을 추가하는 경우, 외부 모델이 중단되는 경우, 운영자가 신고서를 고쳐 내려받는 경우를 추가로 실행했다.

## 2. 바뀐 점과 이유

- 무료 사용 방향에 따라 Gemini REST 어댑터를 추가했다. 기본 감시와 가상 마켓 버튼은 API 호출이 없는 규칙 데모를 실행한다. 실제 모델을 쓰는 감시는 화면에서 명시적으로 선택한다.
- Gemini 2.5 Flash의 신규 사용 제한과 종료 예정 안내를 확인해 무료 등급을 지원하는 안정 API ID `gemini-3.5-flash-lite`를 선택했다. 사용자에게 별도 모델 조합 선택을 다시 요청하지 않고 무료 전환 방향 안에서 구현했다. [모델 안내](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite) · [이전 모델 안내](https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash)
- 키 없는 규칙 데모는 정규식 추출·거래 문구 규칙 군집·템플릿 설명을 사용한다. 데이터 ID나 정답 라벨을 조회해 결과를 채우지 않는다. 화면에 분석 방식을 표시하고 평가의 ai_acceptance_verified를 false로 둔다.
- R2는 같은 공연·회차·좌석의 반복 글을 중복 집계하지 않는다. R5의 크게 낮은 가격은 정가의 절반 미만으로 설정했으며, 이 임계값은 후속 검토 대상이다.
- 승인 대기의 재시작 복구와 일일 한도를 위해 LangGraph 체크포인트 테이블과 api_usage 테이블이 추가됐다. 기존 업무 테이블 8개를 유지했다.
- LLM 설명은 허용 도입 문장 선택과 규칙 템플릿으로 제한했다. 모델이 임의의 사실을 추가하는 자유 서술은 현재 범위에 넣지 않았다. 소명·신고·재배분 문서도 검증된 사실과 템플릿으로 구성한다.
- FastAPI가 화면과 API를 함께 제공하도록 단일 서버 배포를 구성했다.
- 마켓의 표시 가격과 텍스트 추출 근거를 구분했다. 제목과 본문에서 장당 가격·수량·좌석을 읽고 원문을 강조한다. 별도 표시 가격은 마켓에 그대로 보여준다.
- 감시 도중 추출·임베딩 호출이 중단되면 그 단계를 실패로 표시하고 기존 예매 근거와 위험 판정을 보존한다. 이미 성공한 마스킹 텍스트의 추출은 SQLite에 저장해 다음 실행에서 이어 쓴다. 설명만 생성하지 못했을 때는 부분 완료와 규칙 설명을 표시한다.
- 이메일 모양의 가상 작성자 두 명이 같은 마스킹 문구로 표시돼도 각각 독립적으로 묶는다. 작성자 일치 여부는 서버 안에서 비교하며 케이스와 모델 입력에는 마스킹을 적용한다.

현재 사용 가능한 웹 배포 경로는 Cloudflare Worker ES 모듈을 받는다. 기획서의 Python FastAPI·LangGraph·로컬 HTTP 피드를 실행하려면 Python 호스팅 연결이 필요하다. Render·Railway 연결 수단을 검색해 사용할 수 있는 플러그인이 있는 것을 확인했으며, 현재 설치·계정 연결은 되어 있지 않다.

## 8. 알려진 오류와 한계

- Gemini API 키가 없어 실계정 모델 호출·반환 버전·정확도·임베딩 품질·실제 지연을 검증하지 못했다.
- 무료 프로젝트의 실제 한도에 따라 첫 분석과 전체 평가에 시간이 걸릴 수 있다. 캐시와 평가 이어하기를 구현했다.
- 규칙 데모는 가상 데이터 표현을 처리하는 기준선이다. 일반 한국어 게시글 전체에 대한 성능을 보장할 근거는 아직 없다.
- 현재 군집은 동일 작성자나 반복 거래 문구의 보강 근거를 요구한다. Gemini 방식에서도 임베딩 유사도만으로 서로 다른 관객을 합치지 않도록 했다.
- 개인정보 마스킹은 정규식이며 표시되지 않은 이름과 새로운 계좌 형식에는 한계가 있다. 모든 입력은 가상 데이터로 운영한다.
- 같은 서버의 데모 상태를 접속자들이 공유한다. 세션별 샌드박스는 구현하지 않았다.
- 모바일 실제 브라우저와 공개 배포의 시크릿 접근은 미검증이다. 데스크톱 브라우저의 실제 렌더링은 확인했다.
- Docker 이미지 빌드와 장기간 상시 운영은 미검증이다. 제출 소개서·AI 활용내역·최종 제출도 후속 작업이다.

## 9. AI 사용 기록

Claude의 갱신 기획서를 요구사항으로 삼았다. 사용자는 무료 사용 방향과 계속 진행을 지시했다. ChatGPT는 Gemini 연결, 규칙 데모, 예매 매칭·군집·판단, LangGraph 감시와 승인 그래프, SQLite 트랜잭션, 운영자 화면, 평가·검증 코드와 보고서를 작성했다. 모델 조합과 저가 사기 신호의 세부 임계값은 구현 과정에서 선택했으므로 사용자·Claude가 확인해야 한다.

가상 데이터만 사용했다. 실제 플랫폼 수집·실제 개인정보 전송·실제 예매 취소·이메일 발송은 수행하지 않았다. 사용자 본인의 새 실행·모델 검증 결과는 아직 전달받지 않았다.
